1. **Vision Produit IA** : Scoping, priorisation, ROI et éthique des features IA
2. **Socle Technique** : Dialogue fluide avec la Data Science (ML, DL, NLP, CV)
3. **Vibe Engineering** : Prototypage rapide via AI-assisted coding (Claude Code, Copilot, Cline)
4. **Multi-Cloud Mastery** : Hands-on sur IBM Watson, Google Vertex AI et Microsoft Azure
