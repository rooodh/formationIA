# 🧭 Claude Code 101

## 📝 Description

Cours d'entrée pour utiliser Claude Code au quotidien : ce qu'est réellement une boucle agentique, comment la fenêtre de contexte détermine ce que l'agent voit, et comment outils et permissions encadrent ce qu'il peut faire. Le cœur du cours est le cycle Explore → Plan → Code → Commit.

Le cours est désormais hébergé sur Claude Academy (`academy.claude.com`) ; la page Skilljar reste accessible pour les comptes entreprise.

## 🎯 Objectifs d'apprentissage

- Comprendre la boucle agentique et le rôle du contexte
- Installer Claude Code dans plusieurs environnements (terminal, VS Code, JetBrains, Claude Desktop, web)
- Écrire des prompts efficaces dès le premier essai (approval mode, auto-accept, Plan Mode)
- Appliquer le cycle Explore → Plan → Code → Commit sur une tâche réelle
- Revoir du code produit par l'agent
- Gérer le contexte d'une longue session (`/compact`, `/clear`, `/context`)
- Écrire un `CLAUDE.md` pour transmettre les conventions du projet
- Créer des subagents et des skills, brancher des serveurs MCP, poser des hooks
