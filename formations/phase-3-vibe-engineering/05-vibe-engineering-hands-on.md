# 🚀 Vibe Engineering Hands-on : De l'idée au POC

## 📝 Description
Cette session pratique permet de mettre en application toutes les compétences acquises dans les formations précédentes. Le "vibe engineering" fait référence à l'utilisation d'outils d'IA pour accélérer le développement, du prototypage rapide à la création de POCs fonctionnels.

L'objectif est de configurer un environnement de développement optimisé avec les meilleurs outils d'IA (dont Claude Code) et de créer son premier proof of concept en utilisant le "task context coding" pour passer rapidement de l'idée à l'implémentation.

## 🛠️ Outils à configurer

### 1. Cline (Extension VS Code) ⭐
- **Description :** Assistant IA autonome dans VS Code
- **Configuration :**
  - Installer l'extension depuis VS Code Marketplace
  - Connecter votre API key (Claude, OpenAI ou Gemini)
  - Configurer les modèles préférés
  - Personnaliser les règles de contexte
- **Use cases :**
  - Création de fichiers multiples
  - Refactoring de code
  - Génération de documentation
  - Débogage assisté

### 2. Cursor (IDE avec IA intégrée)
- **Description :** Fork de VS Code avec IA native
- **Configuration :**
  - Télécharger depuis cursor.sh
  - Configurer les modèles IA
  - Importer vos paramètres VS Code
  - Activer les fonctionnalités avancées
- **Use cases :**
  - Chat contextuel avec votre codebase
  - Édition multi-fichiers
  - Compréhension de code legacy

### 3. Claude Code CLI
- **Description :** Interface en ligne de commande pour l'édition de fichiers
- **Configuration :**
  - Installer via npm ou pip
  - Configurer l'API key Anthropic
  - Tester les commandes de base
- **Use cases :**
  - Scripts d'automatisation
  - Édition de fichiers directe
  - Intégration dans pipelines CI/CD

### 4. GitHub Copilot
- **Description :** Autocomplétion intelligente dans l'éditeur
- **Configuration :**
  - Activer dans VS Code/Cursor
  - Configurer les suggestions
  - Personnaliser le comportement
- **Use cases :**
  - Écriture rapide de code
  - Génération de tests
  - Documentation inline

## 🎯 Projet Hands-on : Créer son premier POC

### Phase 1 : Idéation (30 min)
- Choisir une idée de POC simple mais fonctionnelle
- Exemples :
  - Chatbot personnalisé
  - Outil de scraping et analyse
  - Dashboard avec visualisation de données
  - API REST simple
  - Extension de navigateur
- Définir les fonctionnalités minimales (MVP)

### Phase 2 : Setup de l'environnement (1h)
- Installer et configurer Cline
- Tester Cursor ou rester sur VS Code
- Configurer GitHub Copilot
- Préparer le repository Git
- Créer la structure de projet avec l'IA

### Phase 3 : Développement assisté par IA (2h)
- Utiliser Cline pour générer la structure de base
- Implémenter les fonctionnalités core avec Copilot
- Itérer avec des prompts précis
- Déboguer avec l'aide de l'IA
- Générer les tests unitaires

### Phase 4 : Documentation et finalisation (1h)
- Générer le README avec l'IA
- Documenter le code
- Créer un guide de déploiement
- Préparer une démo

### Phase 5 : Réflexion et apprentissage (30 min)
- Analyser ce qui a bien fonctionné
- Identifier les limites rencontrées
- Noter les techniques de prompting efficaces
- Planifier les améliorations futures

## 💡 Techniques de "Task Context Coding"

### 1. Fournir un contexte riche
- Inclure les fichiers pertinents dans la conversation
- Partager les spécifications techniques
- Donner des exemples de code existant

### 2. Itération progressive
- Commencer par la structure de base
- Ajouter les fonctionnalités une par une
- Tester fréquemment

### 3. Prompts efficaces
- Être spécifique et détaillé
- Demander des explications
- Inclure les contraintes techniques

### 4. Vérification et validation
- Ne jamais faire confiance aveuglément
- Tester chaque génération
- Comprendre le code produit

## 🎯 Objectifs d'apprentissage
- Configurer un environnement de développement optimisé pour le vibe engineering
- Maîtriser les outils d'IA pour le développement (Claude Code, Cline, Cursor, Copilot)
- Créer un POC fonctionnel en quelques heures
- Apprendre à itérer rapidement avec l'assistance IA
- Développer des compétences en prompt engineering appliqué
