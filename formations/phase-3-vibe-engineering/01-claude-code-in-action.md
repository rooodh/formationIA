# 🤖 Claude Code in Action

## 📝 Description

Cours pratique centré sur l'utilisation de Claude Code pour accélérer le workflow de développement. Couvre les outils intégrés, la gestion du contexte, l'automatisation et l'extension via MCP.

## 🎯 Objectifs d'apprentissage

- Utiliser les outils natifs de Claude Code (lecture de fichiers, exécution de commandes)
- Configurer et maintenir le contexte via `CLAUDE.md` et les `@mentions`
- Maîtriser le Plan Mode et le Thinking Mode pour des tâches complexes
- Créer des commandes personnalisées pour automatiser les workflows répétitifs
- Étendre Claude Code via des serveurs MCP (ex : automation navigateur)
- Intégrer Claude Code dans un workflow GitHub (PR reviews, gestion des issues)
- Écrire des hooks pour personnaliser le comportement de l'agent

## 📚 Contenu / Programme

15 leçons · 1 quiz de validation

| Module | Contenu |
|--------|---------|
| Outils et contexte | Fonctionnement des outils, `/init`, `CLAUDE.md`, `@mentions` |
| Modes avancés | Plan Mode, Thinking Mode, raccourcis clavier |
| Automatisation | Commandes personnalisées, workflows répétitifs |
| Extension MCP | Intégration de serveurs MCP, automation navigateur |
| Intégration GitHub | PR reviews automatiques, gestion des issues |
| Hooks | Extension du comportement de l'agent via hooks |

## 🛠️ Prérequis

- Accès à Claude Code (abonnement ou API key Anthropic)
- Notions de base CLI (terminal, navigation fichiers)
