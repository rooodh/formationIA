# 📝 ChatGPT Prompt Engineering for Developers

## 📝 Description
Dans ce cours, vous apprendrez comment utiliser un grand modèle de langage (LLM) pour construire rapidement des applications nouvelles et puissantes. En utilisant l'API OpenAI, vous serez en mesure de développer rapidement des capacités qui apprennent à innover et à créer de la valeur de manières qui étaient auparavant coûteuses, hautement techniques ou simplement impossibles.

Ce cours court enseigné par Isa Fulford (OpenAI) et Andrew Ng (DeepLearning.AI) décrit comment fonctionnent les LLMs, fournit les meilleures pratiques pour l'ingénierie de prompts, et montre comment les API LLM peuvent être utilisées dans des applications pour diverses tâches.
